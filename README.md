# Exploring NestJS

Learning and exploration project for NestJS framework and best practices.

## Overview
This repository contains examples, experiments, and learning materials for building scalable server-side applications with NestJS.

## What is NestJS?
NestJS is a progressive Node.js framework for building efficient, reliable, and scalable server-side applications. It uses TypeScript by default and combines elements of OOP, FP, and FRP.

## Features Explored
- Controllers and Routing
- Services and Dependency Injection
- Modules
- Middleware
- Pipes and Guards
- Decorators
- Exception Handling
- Validation
- Authentication & Authorization
- Database Integration (TypeORM)
- Testing
- Documentation (Swagger/OpenAPI)

## Technologies
- Node.js
- NestJS
- TypeScript
- Express (underlying HTTP server)
- TypeORM / Prisma
- Jest (Testing)

## Getting Started
```bash
npm install
npm run start:dev
npm run test
```

## Available Scripts
- `npm run start` - Run application
- `npm run start:dev` - Development mode
- `npm run build` - Build for production
- `npm run test` - Run tests
